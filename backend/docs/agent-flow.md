# DevOps AI Agent Flow

## Main Goal
Help users debug deployment, CI/CD, infra, logs, and repo-level issues.

## Core User Inputs
- GitHub repo URL
- Error logs
- Deployment failure message
- CI/CD pipeline issue
- Docker/Kubernetes issue

## Agent Responsibilities
1. Understand user request
2. Detect issue category
3. Fetch required data
4. Analyze context
5. Suggest solution
6. Return structured response

## Categories
- Build Failure
- Deployment Failure
- Docker Issue
- CI/CD Issue
- Infra Misconfiguration
- Log Analysis
